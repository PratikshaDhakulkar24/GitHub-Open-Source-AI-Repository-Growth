# GitHub Open-Source AI Repository Growth

## 📌 About the Project

This is a Python data analytics project that analyzes GitHub AI repositories to understand repository growth, popularity, programming languages, activity, ownership, and open-source licensing trends.

## 🎯 Objective

To explore GitHub AI repository data and identify meaningful technology and community trends using Python and data visualization.

## 🔍 Key Insights

- Repository creation trends over time
- Popular AI domains based on GitHub stars
- Most popular programming languages
- Repository popularity vs community engagement
- Organization vs User repositories
- Repository age vs popularity
- Active vs Inactive repositories
- Open-source license trends
- Repository size vs popularity

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Dataset

The analysis was performed on **4,997 GitHub repository records** after data cleaning and duplicate removal.
